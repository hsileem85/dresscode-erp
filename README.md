# DressCode ERP — نظام إدارة التصنيع وحساب التكاليف

تطبيق ويب عربي كامل (**RTL**) لإدارة تصنيع الملابس وحساب التكاليف والتسعير، مصمّم خصيصاً لعلامة الأزياء النسائية المحتشمة **DressCode** (`dresscode-clothing.com`).

## المزايا الرئيسية
- **لوحة التحكم (Dashboard):** مؤشرات تكلفة الموديلات، رسم بياني دائري لتوزيع هيكل التكلفة (Recharts)، ومقارنة التكلفة بسعر البيع المقترح.
- **إدارة الخامات والكلف (Raw Materials):** قاعدة بيانات للأقمشة بنسب الهالك الافتراضية، وإدارة الكلف والإكسسوارات (تيكت DressCode، سحابات، أزرار، خيوط، تغليف) مع محوّل وحدات تلقائي (دستة / لفة / عبوة ← قطعة).
- **الموديلات وبطاقة التكلفة (Models & BOM):** إنشاء بطاقة تكلفة لكل موديل بعدة أقمشة ونسب هالك وكلف ومراحل تشغيل خارجي.
- **التشغيل الخارجي والورش (Outsourced Labor):** إدارة الورش ومراحل القص والخياطة والسرفلة والكي والتطريز بالقطعة أو بالباتش.
- **حاسبة التكلفة والتسعير والمصاريف غير المباشرة:** توزيع المصاريف الشهرية على حجم الإنتاج المتوقع ومحاكاة هامش الربح وسعر البيع للمتجر.
- **الاستيراد الذكي والتصدير (Excel & JSON):** رفع ملفات `.xlsx` / `.csv` عبر SheetJS مع معاينة وربط تلقائي للأعمدة، وتصدير تقارير إكسل متعددة الصفحات ونسخ احتياطي `JSON` مع حفظ تلقائي في `LocalStorage`.
